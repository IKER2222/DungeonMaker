# DungeonMaker
Dungeon Maker es una aplicación web diseñada para Dungeon Masters y entusiastas del rol que buscan generar aventuras personalizadas y coherentes en segundos. Utilizando modelos de lenguaje avanzados (OpenAI GPT-4o), la plataforma transforma una serie de preferencias y datos específicos en una narrativa estructurada lista para jugar.
